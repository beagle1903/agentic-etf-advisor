# Curated US starter research

The dashboard's **Curated US starter** scope uses twenty packaged US ETF leads and USD cash. It verifies each returned Yahoo listing identity. The funds are research candidates, not a claim of independent economic risks: several may track the same index or hold many of the same securities. The workflow does not certify legal Fund or share-class identity.

In the dashboard, select **Curated US starter**, then choose **Collect current starter data**. Each explicit collection gets its own ignored local run directory. A crashed or completed run is never resumed or overwritten. The collector attempts BND, AGG, SCHZ and SPAB first, then the remaining leads. Each candidate has at most 12 Yahoo requests, 10 seconds per request, a native 2 MiB response ceiling and 45 seconds total (90 for BND); the whole pass has a 900-second ceiling. BND may use one bounded Vanguard holdings client fallback. No provider search, automatic retry or external financial write is performed. The earlier Issue 141 feasibility pass remains under `.artifacts/issue141-source-pass/` and is not rerun.

After collection, choose the prepared source data, enter USD amounts and create a review draft. The starter path requires evidence but no Chroma, Neo4j, curator registry or ECB service. The review shows requested, attempted, collected, screened, eligible, excluded, shortlisted and final counts, plus each lead's reason. Explanation generation remains optional and requires a configured provider. For an audit-only CLI reproduction on a fresh checkout, `uv run python scripts/issue141_source_gate.py` writes one fixed local pass; its existing root prevents reuse.

The saved review embeds the selected prepared evidence. Reopening it validates the saved source and construction without reading Yahoo, the local artifact, packaged universe JSON, the registry or the wall clock. The packaged universe file is checked during explicit preparation; frozen membership and digest are used for offline validation. A new run still checks original source freshness; a stale artifact cannot be refreshed by reopening or preparing it. The source pass is local development evidence, not a complete market catalogue or a suitability recommendation.
